## About

Conv3n is an embeddable workflow automation engine for Go applications.

## Tech Stack

- **Engine**: Go 1.25+ with SQLite
- **Block Runtime**: Bun for TypeScript/JavaScript blocks
- **SDK**: TypeScript SDK for custom block development
