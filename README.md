## About

Conv3n is a lightweight workflow automation engine for neurone engine.

## Fast Start

```bash
# build the engine
make build

# run a workflow
./bin/conv3n 
```

## Tech Stack

- **Backend**: Go 1.24+ with SQLite
- **Runtime**: Bun for custom blocks
- **SDK**: TypeScript SDK for block development
